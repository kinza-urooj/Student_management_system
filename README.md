
# 🎓 Student Management System

A beginner-friendly Student Management System built using Python.

## 📌 About the Project

This project helps users manage student records through a simple menu-driven program.

## ✨ Features

- Add student records
- View all students
- Search for students
- Calculate student grades
- Delete student records

## 🛠️ Technologies Used

- Python 3
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## 🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```
